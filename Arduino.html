About the Project

At the start of this year, our class decided to move into a more physical form of programming that didn't entirely take place on our computers. We started working with Arduinos, which are small microcontroller boards that can be programmed to interact with the physical world. We learned how to use sensors, motors, and other components to create all sorts of cool projects, from simple LED displays to more complex projects. It was a really fun and hands-on way to learn about programming and electronics, and it gave us a chance to see how code can be used to control real-world objects.

My idea for my project was to create a simple number display, both as a digit and the binary equivalent, by using a remote and a receiver. After a couple weeks of troubleshooting, I finally got it to work and I'm very proud of it. You can see it in action below!
