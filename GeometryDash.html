About the Project

During sophomore year, my class's final project was to make a game using many of the skills we learned last year. While some chose to stick to a simple game, I decided I was going to challenge myself and try to make a game that was difficult to make so that it would be so much more fun when I played it.

I've been thinking about how I could make a functioning game of geometry dash since my freshman year, so this seemed like a great oppurtunity to try this. Thanks to the help of Mr. Uhl's videos, I learned about the physics and movements of platformer games. From there, I made it so that the cube would move to the right automatically, and I started to design the level. Using my prior knowledge of incorporating sounds into games and game states, I decided that it would also be a factor here.

I'm very proud of how the game turned out, and below is a video featuring the code, classes, and gameplay of my game.
